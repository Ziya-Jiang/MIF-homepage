# Homepage Assets

Place the final paper media for the GitHub Pages site here.

## Expected files

- `paper.pdf`: the camera-ready paper PDF.
- `images/teaser.jpeg`: hero teaser image.
- `images/pipeline.svg` or `images/pipeline.png`: method overview figure.
- `images/results.svg`: result evidence overview panel.
- `images/ips.svg`: IPS evidence from `pointcloud.png`.
- `images/memory-reduction.svg`: memory-reduction evidence from `Feature_Realtime.pdf`.
- `images/collision-rate.svg`: collision-rate evidence from `Change.pdf`.
- `images/navigation-error.svg`: navigation-error evidence from `Pure_Pursuit.pdf`.
- `images/real-robot.svg`: real robot experiments from `showoff.jpg`.
- `images/meshes.svg`: reconstructed object meshes from `MESHES.png`.
- `images/pcl-vs-mesh.svg`: mesh vs sparse point-cloud comparison from `PCLVSMESH.png`.
- `images/visual-quality.svg`: denoised mapping and appearance-field update from `visual.png`.
- `images/video-poster.svg` or `images/video-poster.jpg`: poster shown before the demo video loads.
- `videos/demo.mp4`: main project video.
- `videos/adaptation.mp4`: optional dynamic-memory update video.
- `videos/interaction.mp4`: optional IPS/manipulation-safety video.

The remaining placeholder media are the paper PDF, video files, and video poster.
