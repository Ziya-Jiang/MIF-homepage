# MIF Paper Homepage

This repository contains a GitHub Pages-ready project homepage for:

**Learning to Evolve: Multi-modal Interactive Fields for Robust Humanoid Navigation in Dynamic Environments**

## Local files

- `docs/index.html`: the homepage.
- `docs/style.css`: responsive styling.
- `docs/assets/`: paper PDF, images, and videos used by the page.

## Add final assets

Before publishing, replace the placeholders with the final paper media:

- `docs/assets/paper.pdf`
- `docs/assets/images/teaser.jpeg`
- `docs/assets/images/pipeline.svg` or update the HTML to use your final pipeline image
- `docs/assets/images/results.svg` or update the HTML to use your result image
- `docs/assets/images/video-poster.svg`
- `docs/assets/videos/demo.mp4`

## Publish with GitHub Pages

1. Push this project to a GitHub repository.
2. Open the repository on GitHub.
3. Go to `Settings` -> `Pages`.
4. Set `Source` to `Deploy from a branch`.
5. Select the `main` branch and the `/docs` folder.
6. Save and wait for GitHub to provide the public URL.

The `.nojekyll` file in `docs/` tells GitHub Pages to serve the static files directly.
